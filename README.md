## What it does

`main.py` writes one funny one-line review of my Monday to `/output/entry.txt`. The line is fixed, so every run produces the exact same output. No network, no input files, no dependencies beyond Python 3.

The line:

> Monday review: my 9am standup ran 40 minutes, my inbox hit triple digits, and my coffee filed for overtime. One star, would not recommend.

## Run it

```sh
python3 main.py
```

Set `OUTPUT_PATH` to write somewhere else, for example:

```sh
OUTPUT_PATH=/tmp/out/entry.txt python3 main.py
```
